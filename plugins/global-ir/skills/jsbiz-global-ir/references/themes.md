# 디자인 테마 5종

스펙의 `"theme"` 키로 선택. 모든 테마는 같은 레이아웃·역할 체계를 쓰므로 테마만 바꿔 재빌드해도
레이아웃이 깨지지 않는다. 폰트는 전 테마 Arial 고정(해외 어느 PC에서 열어도 동일 렌더링).

| 테마 | 성격 | 어울리는 업종 |
|---|---|---|
| `ocean` (기본) | 딥네이비+틸+민트. 신뢰·클린테크 | 하드웨어, 환경, 헬스케어, IoT, 제조 |
| `midnight` | 짙은 남색+아이스블루. 기업용·금융 톤 | B2B SaaS, 핀테크, 보안, 데이터 |
| `forest` | 포레스트그린+모스. 지속가능성 | 농식품, ESG, 바이오, 에너지 |
| `terracotta` | 테라코타+세이지. 따뜻한 소비자 톤 | 커머스, F&B, 라이프스타일, 여행 |
| `charcoal` | 차콜+앰버. 미니멀 프리미엄 | 디자인, 럭셔리, 콘텐츠, AI |

## 역할(Role) 체계

스펙과 런 배열에서 색은 hex가 아니라 역할명으로 지정한다(테마 전환이 가능해지는 이유):

- `DEEP` 다크 슬라이드 배경 / `HEAD` 제목 / `SUB` 보조 강조(아이콘·차트 기본색)
- `ACCENT` 포인트(하이라이트·CTA 밴드·target 막대) / `ACCENT_TINT` 하이라이트 카드 배경
- `LIGHT` 카드 틴트 / `ICE` 다크 배경 위 본문 / `TXT` 본문 / `MUT` 보조 텍스트
- 고정색: `WHITE` `RED`(✗) `AMBER`(△) — 의미색은 테마와 무관하게 유지

## 선택 가이드

1. 회사 브랜드 컬러가 뚜렷하면 가장 가까운 테마를 고른다(로고와 충돌하는 테마 금지 — 예: 빨간 로고에 forest).
2. 업종 무드가 우선, 못 정하면 ocean.
3. 사용자가 원하면 같은 스펙으로 2개 테마를 빌드해 비교 렌더를 보여주고 고르게 한다(테마 전환 비용은 재빌드 1회).
