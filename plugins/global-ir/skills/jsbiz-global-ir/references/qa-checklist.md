# QA 체크리스트

render_qa.py로 만든 PNG를 슬라이드마다 Read 도구로 열어 확인한다.
"스펙이 빌드됐다 ≠ 슬라이드가 멀쩡하다."

## 시각 검수 (슬라이드별)

- [ ] 텍스트 오버플로/잘림 없음 (박스 경계·슬라이드 경계) — **가장 흔한 결함, 최우선 확인**
- [ ] 요소 겹침 없음 (캡션↔사진, 카드↔카드)
- [ ] **이미지가 내용과 일치** — 실증 사진 자리에 엉뚱한 사진이 들어가는 것이 이 파이프라인의 대표 실수. 캡션과 사진을 대조할 것
- [ ] 이미지 속 한글 잔존 없음 (크롭 후에도 얇은 색 밴드·작은 글자가 남는 경우가 있다 — 의심되면 크롭을 더 깊게)
- [ ] 차트 데이터 라벨이 원본 수치 그대로인지 (정수 반올림 1.13→1 같은 오류는 number_format 미지정이 원인)
- [ ] 사진 종횡비 왜곡 없음 (스펙에 w·h를 둘 다 강제로 넣으면 왜곡된다 — 빌더의 자동 비율 계산에 맡길 것)
- [ ] 로고 가독성 (다크 배경엔 whiten 처리된 로고인지)

## 콘텐츠 검수 (덱 전체)

- [ ] 슬라이드의 모든 숫자가 ②단계 사실 인벤토리에 존재 (출처 없는 숫자 = 삭제 후 [확인 필요]로)
- [ ] 시장 수치에 출처 병기
- [ ] 밸류에이션·라운드명 미기재
- [ ] "the only ~" 문장 1개, 비유 1개 이하
- [ ] 슬라이드당 정보 7개 이하
- [ ] 스크립트 총 단어수 = 발표시간 × 140단어 ±15%
- [ ] 노트 스크립트가 단문인지 (연결어 남용 없는지)

## 가이드 MD 검수

- [ ] [확인 필요] 섹션 존재 (로마자 표기·행사명·인증 체계·미확인 수치)
- [ ] Q&A에 "Who is your customer?"와 Exit 질문("Who would buy you?") 포함
- [ ] 원본 덱을 Appendix로 지참하라는 안내 포함

## 수정 루프

문제 발견 → 스펙(또는 자산) 수정 → 재빌드 → `render_qa.py --slides N M`으로 바뀐 슬라이드만 재렌더 → 재확인.
2회 이상 같은 유형의 결함이 나오면 개별 수정 대신 원인(크롭 값, 텍스트 길이)을 고친다.
