jsbiz-global-ir는 갖고 있는 IR 자료(PDF/PPT)를 넣으면, 해외 심사역 눈높이의 영문 10장 발표덱과 영어 스크립트까지 만들어 주는 Claude Code 스킬입니다. 번역이 아니라 Y-Combinator·German Accelerator 피칭 방법론으로 스토리를 다시 짜는 것이 핵심입니다.

영문 10장 피칭덱 (PPTX)

표지 → 회사 → 제품 → 문제 → 기존 솔루션 한계 → 기술 → 트랙션 → 진출 전략 → Ask → 팀. 원본 덱의 제품 사진·인증서·실증 자료를 자동으로 추출해 그대로 살립니다.

준비물 — 처음 한 번만

① Claude Code 설치

Anthropic의 AI 코딩 도우미입니다. 코딩용이지만 이런 문서 작업도 훌륭하게 해냅니다. claude.com/claude-code에서 내 컴퓨터(Windows/Mac)에 맞게 설치하고, Claude 계정으로 로그인하세요. 데스크탑 앱 또는 터미널 어느 쪽이든 됩니다.

② Python 설치

python.org에서 최신 버전을 설치합니다. Windows는 설치 첫 화면에서 "Add Python to PATH" 체크박스를 꼭 켜 주세요. Mac은 대부분 이미 설치되어 있습니다.

③ 필요 라이브러리 설치

터미널(Windows: PowerShell / Mac: 터미널)을 열고 아래 한 줄을 붙여넣으세요.

pip install python-pptx pymupdf pillow
선택 사항 컴퓨터에 PowerPoint 또는 LibreOffice가 있으면 Claude가 완성된 슬라이드를 이미지로 렌더링해서 스스로 검수까지 합니다. 없어도 덱은 정상적으로 만들어지며, 마지막 확인만 직접 하시면 됩니다.
1

스킬 설치 — 두 줄이면 끝

Claude Code를 실행하고, 채팅창에 아래 두 명령을 차례로 입력합니다.

/plugin marketplace add aqualife75/jsbiz-global-ir
/plugin install global-ir@jsbiz

설치가 끝나면 새 세션(새 대화)을 시작하세요. 이제 스킬이 자동으로 준비되어 있습니다.

2

실행 — 한 문장으로 요청

내 IR 덱 파일(PDF 또는 PPTX)을 준비하고, 아래 템플릿의 [ ] 부분만 바꿔 붙여넣으세요. 파일 경로는 파일을 채팅창에 드래그&드롭하면 자동으로 입력됩니다.

[내 IR덱.pdf] 를 [싱가포르 데모데이]용 영어 [3]분 발표 덱으로 재구성해줘.
청중은 [데모데이 심사역과 현지 기업]이고, Ask는 [현지 파트너 발굴 + 투자 유치]야.

그 다음은 Claude가 알아서 진행합니다. 보통 10~15분이 걸립니다.

원본 덱 판독모든 페이지를 읽고 매출·인증·실증 같은 사실 목록을 만듭니다
증거자료 추출제품 사진·인증서·고객 로고를 원본에서 뽑아내고, 한글이 박힌 이미지는 잘라냅니다
스토리 재구성YC·독일 액셀러레이터 방법론으로 10장 구성과 영어 스크립트를 작성합니다
덱 생성 + 자동 검수PPTX를 만들고 슬라이드를 하나씩 렌더링해 겹침·오류를 스스로 고칩니다
TIP 중간에 Claude가 행사명·발표시간 등을 물어볼 수 있습니다. 아는 만큼만 답하면 되고, 모르는 건 "아직 미정"이라고 하면 기본값(3분·데모데이)으로 진행합니다.

결과물 확인 — 이 3가지만 보세요

① 발표자 노트에서 영어 스크립트 보기

PPTX를 열고 PowerPoint 메뉴에서 보기 → 슬라이드 노트(또는 하단 "메모" 버튼)를 누르면 슬라이드마다 그대로 읽으면 되는 영어 대본이 들어 있습니다. 짧은 문장으로 되어 있어 외우기 쉽습니다.

② 가이드 문서의 [확인 필요] 목록

가장 중요 가이드 문서 끝의 [확인 필요] 목록은 발표 전에 반드시 직접 확인하세요. 이 스킬은 원본에 없는 숫자를 지어내지 않는 대신, 확인이 필요한 것(이름 영문 표기, 행사 공식 명칭, 해외 인증 여부 등)을 이 목록에 모아 둡니다. 슬라이드의 모든 숫자와 회사 정보의 최종 책임은 발표자에게 있습니다.

③ 예상 Q&A

해외 심사역이 거의 반드시 묻는 질문("고객이 정확히 누구인가?", "누가 당신 회사를 인수할 것 같은가?")과 답변 방향이 정리되어 있습니다. 발표 연습할 때 함께 소리 내어 연습하세요.

수정 요청은 대화로

다시 처음부터 만들 필요 없습니다. 같은 대화에서 이렇게 요청하면 몇십 초 안에 해당 부분만 고쳐서 다시 만들어 줍니다.

3번 슬라이드 제품명을 "AirPure Pro"로 바꿔줘
7번 슬라이드 매출 숫자를 2.1억으로 수정해줘
테마를 midnight로 바꿔서 다시 만들어줘
5분 발표 버전으로 스크립트를 늘려줘

부록 — OpenAI Codex에서도 쓸 수 있나요?

네, 가능합니다(고급 사용자용). Claude Code 없이 OpenAI의 Codex CLI를 쓰는 분은 저장소를 통째로 내려받아 그 폴더 안에서 실행하면 됩니다. 저장소에 들어 있는 AGENTS.md 파일이 Codex용 작업 지침서 역할을 하며, Codex가 자동으로 읽습니다.

git clone https://github.com/aqualife75/jsbiz-global-ir
cd jsbiz-global-ir
pip install python-pptx pymupdf pillow
codex

그 다음 Codex에게 STEP 2와 같은 문장으로 요청하면 됩니다.

알아두세요 스킬 자동 발동과 덱 여러 개 병렬 처리는 Claude Code 전용 기능입니다. 또한 Windows에서 Codex CLI는 WSL(리눅스 환경) 설치를 권장하므로, 비개발자라면 Claude Code 경로를 추천합니다.

자주 묻는 질문

코딩을 전혀 모르는데 할 수 있나요?

네. 설치 단계(위의 0~1번)만 넘기면 그 다음은 전부 한국어 대화입니다. 명령어는 이 페이지의 "복사" 버튼으로 붙여넣기만 하면 됩니다.

"pip를 찾을 수 없다"는 오류가 나요.

Python 설치 때 "Add Python to PATH"를 체크하지 않은 경우입니다. Python을 다시 설치하면서 체크박스를 켜 주세요. 그래도 안 되면 python -m pip install python-pptx pymupdf pillow로 시도해 보세요.

Mac에서도 되나요?

네. Windows·Mac 모두 지원합니다. 슬라이드 자동 검수는 PowerPoint(Windows) 또는 LibreOffice(무료, Mac/Windows)가 있으면 더 정밀해집니다.

"렌더러가 없어 텍스트 검수로 대체했다"고 나와요.

PowerPoint/LibreOffice가 없는 환경입니다. 덱 자체는 정상적으로 만들어졌으니, 파일을 열어 슬라이드가 깨진 곳이 없는지 직접 한 번 훑어보시면 됩니다. LibreOffice(무료)를 설치하면 다음부터 자동 검수됩니다.

영어를 잘 못하는데 발표할 수 있을까요?

스크립트가 일부러 짧은 문장(1문장 = 1정보)으로 작성됩니다. 이 방식이 원어민식 긴 문장보다 전달력이 좋고 외우기도 쉽습니다. 가이드 문서의 발표 연습 팁을 따라 소리 내어 연습하세요.

제 IR 자료가 외부로 나가지 않나요?

모든 파일 처리(이미지 추출·덱 생성)는 내 컴퓨터 안에서만 이루어집니다. 다만 덱의 텍스트 내용은 Claude(Anthropic)와의 대화로 처리되므로, 회사의 보안 정책상 AI 입력이 금지된 극비 자료라면 해당 수치를 가리고 사용하세요.

영문 덱을 처음부터 새로 만들어 줄 수도 있나요?

이 스킬은 "기존 덱의 재구성" 전용입니다. 덱이 아예 없다면 먼저 국문 초안을 만든 뒤(정석Biz 영상 참고) 이 스킬로 재구성하는 순서를 추천합니다.
